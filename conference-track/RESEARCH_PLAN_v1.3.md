## 2. 会议核心故事（本版）

> 小样本、高相关特征条件下，基于马氏距离的轴承异常检测会出现系统性误报；
> 误报对应的是**含近共线特征组的距离膨胀**，而训练集解析式的收缩/条件数准则
> 能稳定缓解这种膨胀。
> 附带一条方法学结论：**功效不足的阴性结果应报告为"无法判定"，而不是"被反驳"**。

核心链条：

```text
Baseline → Feature Ablation → 条件数受控对照 → 误差定位
        → 三折前瞻验证（H2 一致 / H1 功效不足）
        → 方法学结论 + 缓解方案
```

## 3. 内容边界

保留：核心问题、关键受控实验、主要失败案例、功效分析、核心图表。

可以省略：跨数据集细节、真实设备实验（留给期刊线）。

不得省略：样本量与功效、数据划分原则、H1 的"无法判定"状态、核心限制。
