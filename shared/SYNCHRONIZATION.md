# 双线同步推进

| 阶段 | Conference Track | Journal Track |
| --- | --- | --- |
| EXP-V1-01 ~ EXP-V1-03 | 共同积累 | 共同积累 |
| EXP-V1-04 | 关键决策门 | 关键决策门 |
| EXP-V1-05 | 视结果作为会议增强实验 | 重点机制验证 |
| EXP-V1-06 ~ EXP-V1-07 | 精选核心结果 | 系统稳健性分析 |
| EXP-V2-01 | 通常省略或简化 | 重要泛化验证 |
| EXP-V2-02 | 通常不作为首要内容 | 重要增强内容 |
| 最终 | 阶段性成果（最小完整闭环） | 完整研究论文 |

## 同步规则

1. 每条线的每次版本更新都必须引用同一份 Master 结果。
2. 会议线的结论不能超出 Master 中已冻结的结果范围。
3. 期刊线新增实验必须登记在 Master 仓库后再写入计划。
4. 若 EXP-V1-04 的判定从 C 变为 A 或 B，两条线同时更新，不允许只改一条。
5. 若某条线长期无进展（> 4 周），在 `STATUS.md` 写明原因，而不是修改计划掩盖。
