## 1. 契约（摘要）

| 项目 | 内容 |
| --- | --- |
| 定位 | 机制验证优先、修复验证并行；目标不是提高 F1 |
| H1（方向归因） | 问题组的距离膨胀可归因到最小特征值方向 |

## 3. 待审查：初步判定（草案）

| 项目 | 初步判定 | 说明 |
| --- | --- | --- |
| H1 方向归因 | 部分支持 | 问题组 93.7% 的 D² 来自最小方向；但对照组也出现对齐（88.8%），"对齐"不充分 |
| H2 正则化 | 部分支持 | LW 使问题组 FP 9→1、膨胀 1.58→0.31；反例组不变；对照组略变差（2→3） |
| 条件数 | 仍不能作为主机制 | 反例组同样病态却无膨胀 |
| 新问题 | **收缩强度的选择准则** | LOO 似然选 δ=0（无效），LW 解析式选 0.220（有效）——无测试数据的可靠选择尚未解决 |

## 4. 风险审查要点

1. 只有 1 个正常测试文件（11 个窗口），FP 分辨率为 1/11。
2. 对照组 LW δ=1.000 为退化情形（协方差被完全丢弃）。
3. 三组共享同一划分，无法排除划分特异性。
4. "标准化投影幅度"是事后归纳的描述，尚未经过预先定义假设的检验。
