# 发表伦理与重复发表控制

## 原则

1. 会议论文与期刊论文必须有**实质性内容差异**，不能把会议论文原样扩写后重复投稿。
2. 期刊版本建立在会议论文基础上时，必须按要求**披露前序工作**。
3. 新增内容必须真正增强科学证据（新实验、新分析、新方法、新数据），
   不能为了满足"扩展"要求制造无意义实验。

## 投稿前必查（以目标 venue 官方规定为准）

- [ ] prior publication 政策
- [ ] extended version 政策与允许的重叠比例
- [ ] 版权与预印本（arXiv/机构库）规定
- [ ] 作者贡献声明
- [ ] 数据与代码可用性声明
- [ ] AI 使用披露要求

## 与本研究的具体对应

| 内容 | 会议版 | 期刊版 |
| --- | --- | --- |
| 核心失败机制与受控实验 | 主体 | 引用并扩展 |
| 稳健性/跨数据集/真实实验 | 通常省略 | 新增（实质性扩展） |
| 更完整的 failure analysis 与 limitations | 精简 | 完整 |

## 记录要求

每次投稿前，在本仓库 `CHANGELOG.md` 中记录：

1. 与前一版本的内容差异（对应 保留/删除/修改/新增/延后/因结果改变）
2. 新增实验编号与 Master 提交哈希
3. 目标 venue 的重复发表政策核对结果
