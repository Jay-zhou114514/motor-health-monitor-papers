# 双线共同决策门：EXP-V1-04

## 1. 实验契约（摘要）

| 项目 | 内容 |
| --- | --- |
| Hypothesis | 若误报部分来自协方差病态，则条件数更低的特征组合应当误报更少、阈值更稳定 |
| Control | 数据、划分、窗口、方法、协方差估计、分位数 0.99、阈值推导、评价协议全部固定，只改特征集 |
| Train | baseline_1 + baseline_2（22 个正常窗口） |
| Test | 1 正常 + 3 外圈 + 2 内圈（42 个窗口，31 个故障） |
| Source | Master 仓库 `src/exp_conditioning_control.py`、`experiments/EXP-V1-04-*` |

## 3. 假说判定（草案，待正式审查）

| 预测 | 判定 | 说明 |
| --- | --- | --- |
| 条件数 ↑ → FP ↑ | 部分支持，但不能作为主机制 |
| 条件数 ↑ → 阈值不稳 | 目前不支持 |
| RMS + 谱质心存在特殊问题 | 有较强实验线索 |
| "低方差方向导致距离膨胀" | 合理假说，尚未证实 |
| 经验协方差估计误差是重要因素 | 合理，但尚未单独验证 |
| A 收缩协方差 | 应该做 |
| B 方向归因 | 必须做 |
| C 稳健性扩展 | 暂时不要做 |

精炼后的机制表述：当前结果提示，误报**可能**与 RMS–谱质心近共线结构及其对应低方差方向
与正常文件间分布差异的对齐有关（合理假说，尚未证实）。

## 4. 风险审查要点

1. 11 个特征集是嵌套、非独立样本 → Spearman 的 p 值只能作描述性；Bonferroni 校正后不显著。
2. 测试正常只有 1 个文件、11 个窗口 → FPR 分辨率只有 1/11。
3. 窗口 50% 重叠 → 有效样本量低于窗口数。
4. "膨胀比 > 1 ↔ 含 RMS+谱质心"属于事后观察，需预先定义的新实验验证。
5. 经验协方差在 n = 22 下的估计误差未单独量化。

## 5. 分支选择（按《双线论文计划》）

| 分支 | 条件 | 后续动作 |
| --- | --- | --- |
| A：支持病态协方差假说 | 受控实验 + 替代解释被排除 | 进入 EXP-V1-05 Shrinkage Covariance |
| B：不支持 | 数据与预测不一致 | 弱化/撤回该解释，重新检查 threshold、distance distribution、feature geometry |
| C：部分支持但证据不足 | 方向一致，但功效/独立性不足 | 明确证据强度，设计更严格验证后再决定是否进入 shrinkage |

**当前所处分支：C 已确认（2026-09-15 项目负责人审查）。** 处理方式：
不放弃该方向，但也不把它当作已证实机制——V1-05 以"机制验证优先、修复验证并行"的方式做受控验证；
C 类（跨数据集/真实设备）稳健性扩展**暂缓**。

## 6. 什么证据会把判定推向 A 或 B

推向 A（支持）需要：

- 在预先定义的受控实验中，降低条件数可持续降低误报与距离膨胀比；
- 且该效果不能由特征数量、阈值选择或测试文件差异解释。

推向 B（不支持）会出现：

- 良态化之后误报不降（说明病态不是原因）；
- 或误报可由阈值/距离分布等其他机制更好解释。
