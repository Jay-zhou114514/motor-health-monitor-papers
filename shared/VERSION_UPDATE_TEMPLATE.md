# 版本更新模板

复制以下结构，为每条线各自生成新版本。

```markdown
# <Track> 研究计划 v<X.Y>

- Version：
- Update basis（本版依据的实验编号）：
- Current stage：
- Next experiment：
- Update principle：Experimental-result-driven iterative planning

## 1. 已确认事实
（只写有受控实验支持、且证据等级为 A/B 的内容，注明实验编号）

## 2. 被否定或弱化的假设
（写明原假设、被什么证据否定、弱化到什么程度）

## 3. 当前最可信机制
（最多 3 条，每条标注证据等级 A/B/C/D）

## 4. 当前最大科研风险
（样本量、独立性、多重比较、泛化性）

## 5. 下一实验及理由
- 实验编号：
- 可检验预测：
- 控制变量：
- 判据：

## 6. 论文故事如何随证据变化
（相对上一版，哪些表述必须修改或撤回）
```

## CHANGELOG 记录格式

| 条目 | 处理 | 说明 |
| --- | --- | --- |
| ... | 保留/删除/修改/新增/延后/因实验结果而改变 | ... |

## 证据等级

| 等级 | 含义 |
| --- | --- |
| A | 本数据集内受控实验证实 |
| B | 与证据一致，需进一步确认 |
| C | 尚未成立（置信区间重叠、无法排除随机波动） |
| D | 未知（跨数据集、真实设备） |
