# Journal Track 研究计划 v1.0

- Version：v1.0
- Update basis：EXP-V1-01 ~ EXP-V1-04
- Current stage：Failure Mechanism Investigation
- Next experiment：待 EXP-V1-04 完成结果审查与假说判定后决定（不预先锁定）
- Update principle：Experimental-result-driven iterative planning

## 1. 期刊版要回答的三个问题

1. **问题是什么**：简单、可解释的检测方法在严格评估下会出现什么系统性失败？
2. **为什么发生**：哪些可验证机制能够解释这些失败？
3. **如何解决并泛化**：什么稳健策略有效，结论是否跨数据集 / 真实条件成立？

## 3. 与会议线的关系

- 会议线提供核心发现；期刊线在其上增加**实质性**新实验与新分析。
- 期刊版必须明确披露会议版内容，并说明新增贡献（见 `EXTENSION_POLICY.md`）。
- 若会议线的核心结论在后续实验中被削弱，期刊线必须同步修正，而不是保留旧表述。

## 4. 阶段产出

1. Results Freeze（冻结结果：脚本 + 参数 + 划分 + CSV）
2. 扩展分析（稳健性、统计、失败模式分类）
3. 完整 Limitations 与 Discussion
4. 论文初稿 + 内部审查
5. GitHub / Portfolio / CV 的成果表述同步

## 5. 当前最大风险

1. 样本量与统计功效不足，机制结论难以达到 Level A。
2. 现象可能只存在于当前数据划分（需要 V1-07 / V2-01 检验）。
3. 若扩展到跨数据集，域偏移可能掩盖原机制，需要重新界定研究问题。
