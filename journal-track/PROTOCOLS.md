# 扩展实验协议骨架

所有协议都遵循：契约在跑之前写定；阈值只用训练/验证数据确定；测试只用于评价。

---

## EXP-V1-05 Shrinkage Covariance（条件触发）

- **进入条件**：EXP-V1-04 判定为分支 A（支持病态协方差方向）
- **Hypothesis**：把经验协方差替换为收缩估计后，含近共线特征对的集合
  其距离膨胀比与误报应当下降。
- **Control**：数据、划分、特征集、分位数、阈值推导、评价协议保持不变，
  只替换协方差估计（经验 vs 收缩，如 Ledoit–Wolf）。
- **必须避免**：用测试集选择收缩强度 λ；λ 必须在训练/验证内确定。
- **Metrics**：膨胀比、FP、FPR、F1、阈值、距离分布。
- **Judgement**：误报与膨胀比是否显著下降；是否引入漏报。

## EXP-V1-06 扩展阈值敏感性

- **Hypothesis**：研究结论是否依赖某一个特定阈值。
- **Control**：特征集、数据划分、协方差估计固定。
- **Metrics**：FP、TN、TP、FN、FPR、F1、Recall，覆盖更细的阈值网格
  （如 q = 0.95 / 0.975 / 0.99 / 0.995 / 0.999，以及方法 A 的 k = 2~4）。
- **Judgement**：是否存在"稳定性能区域"；结论在阈值变化下是否保持。

## EXP-V1-07 特征稳定性 / 跨文件稳健性

- **Hypothesis**：EXP-V1-02/04 的发现是否只在单一划分下成立。
- **Method**：对每个测试文件分别报告 FPR、Recall、距离分布、条件数；
  若有可能，做逐文件留一（leave-one-file-out）复核。
- **Metrics**：跨文件的指标方差、最差文件表现。
- **Judgement**：现象是否具有跨文件一致性。

---

## EXP-V2-01 跨数据集验证

- **Hypothesis**：机制（近共线 + 方向一致 → 膨胀 → 误报）是否跨数据来源出现。
- **Design**：Dataset A 训练 → 冻结模型 → Dataset B 测试。
- **Metrics**：性能下降幅度、距离分布位移、阈值可迁移性。
- **Judgement**：机制是否一致，还是被域偏移掩盖。
- **风险**：采样率、载荷、传感器差异会引入新的混杂因素，必须单独报告。

## EXP-V2-02 独立真实实验

- **前置**：先冻结模型、特征集、阈值与评价协议。
- **阶段 1**：健康状态 + 转速 / 负载 / 安装条件变化。
- **阶段 2**：可控异常（如有条件）。
- **记录**：采样率、转速、负载、传感器位置、设备信息、时间戳。
- **Judgement**：方法在独立条件下是否仍可用；失败模式是否与公开数据一致。
- **风险**：设备与传感器差异大，需明确这是外部验证而非同分布测试。
