# Journal Track

目标：在会议核心成果之外，形成更完整的证据链，系统研究**机制、稳健性与泛化**。

本目录包含：

| 文件 | 用途 |
| --- | --- |
| `RESEARCH_PLAN_v1.0.md` | 期刊线计划（随实验结果升级版本） |
| `STATUS.md` | 当前状态与风险 |
| `PAPER_OUTLINE.md` | 期刊论文骨架与扩展章节 |
| `EXTENSION_POLICY.md` | 会议→期刊的扩展与披露规则 |
| `PROTOCOLS.md` | 各扩展实验的契约骨架 |

注意：本目录中的实验顺序**不是预先锁定的路线**；
每个实验是否执行，由上一实验的结果审查与假说判定决定。
