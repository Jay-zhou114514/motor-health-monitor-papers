# 会议 → 期刊扩展政策

## 允许的扩展方式

必须以**实质性新增**为前提，例如：

1. 新增实验：稳健性、跨数据集、真实设备数据。
2. 新增分析：机制分解、失败模式分类、统计检验。
3. 新增方法：更稳健的协方差估计或检测策略，且有受控验证。

## 不允许的扩展方式

- 仅改写文字、重排图表、增加引用。
- 把会议论文的同一实验换参数重复报告。
- 为满足"扩展"要求而制造无科学意义的实验。

## 必须披露的信息

- 前序会议论文的完整引用
- 新增实验编号（Master 仓库）与提交哈希
- 相对会议版的新增贡献清单
- 目标期刊的 prior publication / extended version 政策核对结果

## 检查表

- [ ] 新增实验已登记在 Master 仓库并且可复现
- [ ] 会议版与期刊版的结论差异已说明
- [ ] 若结论变化，已按新版计划修正表述
- [ ] 已核对并记录目标 venue 政策
